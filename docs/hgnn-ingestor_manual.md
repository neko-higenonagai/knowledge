# Ingestor (hgnn-ingestor.py) PDF取り込み

## 概要

`hgnn-ingestor.py` は、PDFや画像ファイルからテキストを抽出（OCR）してデータベースを構築するためのツールです。新しい資料を追加する際や、既存データのメンテナンスに使用します。

## 画面構成と機能

### 1. トップバー（画面最上部）

- **ベースフォルダ**: 監視対象となるルートディレクトリが表示されます。「変更」ボタンで切り替え可能です。
- **DB新規作成**: 既存のデータベースをやめて新しいデータベースファイルを作成します。
- **設定**: NDLOCR-Lite（文字認識エンジン）の詳細設定ダイアログを開きます。

### 2. 左パネル：取り込み操作/リスト

- **ファイル選択 / フォルダ選択**: 取り込みたいファイルやディレクトリをリストに追加します。
- **取り込み開始**: リストでチェックが入っているファイルのOCR処理を開始します。
- **中断**: 実行中の処理を安全に停止します。
- **修正モード（チェックボックス）**:
  - **ONにすると**: 既存の登録データの修正や削除が可能になります。
- **強制更新モード（チェックボックス）**: ONにすると、既に登録済みのファイルも上書きで再処理します。通常は既登録ファイルは確認ダイアログが表示されますが、このモードではすべて上書きされます。
- **ファイル一覧**:
  - **フィルタ**: 「すべて」「登録済み」「未登録」「範囲外」で表示を絞り込めます。
  - **色分け**: 青色は登録済み、赤色は範囲外（深すぎる階層など）を示します。

### 3. 左パネル：テキスト表示

- **テキスト表示エリア**: 選択中のページから抽出されたテキストが表示されます。
- **OCR処理中インジケーター**: 処理が走っている間は、進捗を示すスピナーが表示されます。
- **更新 (修正反映) / ページ削除**: 修正モード中のみ有効。個別のページデータの修正を行います。

### 4. 右パネル：PDFビューアー

- **内容確認**: 取り込み中の書類の内容をリアルタイムで確認できます。
- **外部アプリで開く**: Acrobat等で開き、印刷などを行うことができます。

## 設定画面の項目説明（NDLOCR-Lite 詳細設定）

トップバーの「設定」ボタンから開く設定ダイアログの各項目について説明します。これらの設定はOCR（文字認識）エンジンの精度や速度に影響します。

| 項目名 | 設定キー | 既定値 | 説明 |
|---|---|---|---|
| **検出スコア閾値** | `ocr_det_score_threshold` | `0.2` | テキスト領域として認識する際のスコアの最低基準値です（0.0〜1.0）。値を下げるとより多くの領域を検出しますが、誤検出が増える可能性があります。値を上げると確実な領域のみ検出します。 |
| **検出信頼度閾値** | `ocr_det_conf_threshold` | `0.25` | 検出されたテキスト領域の信頼度の最低基準値です（0.0〜1.0）。信頼度がこの値を下回る検出結果は除外されます。ノイズの多い画像では値を上げると精度が向上します。 |
| **重複(IoU)閾値** | `ocr_det_iou_threshold` | `0.2` | 重複する検出領域を統合する際のIoU（Intersection over Union）の閾値です（0.0〜1.0）。値を下げると重複領域がより積極的に統合され、値を上げると個別に認識されます。 |
| **PDFレンダリング解像度** | `ocr_scale` | `2.0` | PDFをOCR用の画像に変換する際の拡大倍率です（0.5〜5.0）。値を大きくすると文字が鮮明になりOCR精度が向上しますが、処理時間とメモリ使用量が増加します。 |

### PDFレンダリング解像度の目安

| 解像度 | 用途 |
|---|---|
| `1.5` | 速度最優先。文字が大きい資料向け。 |
| `2.0` | 通常使用（既定値）。大半の資料で十分な精度が得られます。 |
| `2.5〜3.0` | 小さい文字や細かい図表がある資料向け。 |
| `3.0以上` | 極めて細かい文字の読み取りが必要な場合。処理時間が大幅に増加します。 |

> **注意**: 設定を変更して保存すると、次回のOCR処理から新しい設定が適用されます。すでにロード済みのモデルは次回実行時にリセットされます。

## 基本的な使い方

### 新規取り込み

1. 「フォルダ選択」でPDFが入っているフォルダを選びます。
2. リストにファイルが表示されるので、取り込みたいものにチェックを入れます。
3. 「取り込み開始」を押すと、順次OCR処理が行われ、DBに登録されます。

### データの修正

1. 「修正モード」にチェックを入れます。
2. リストからファイルを選び、ビューアーでページを移動します。
3. OCRの誤りがあればテキストエリアを直接書き換え、「更新（修正反映）」を押します。
