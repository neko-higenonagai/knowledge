# Editor (hgnn-editor.py) PDF Editor

## 概要

`hgnn-editor.py` は、PDFのページ構成を変更するための編集ツールです。ページの並べ替え、削除、回転、および別ファイルの挿入といった操作が行えます。

## 画面構成と機能

### 1. トップバー（画面最上部）

- **PDFを開く**: 編集したいファイルを選択します。画像ファイルを選択した場合は自動的にPDF化して読み込まれます。
- **アンドゥ / リセット**: 操作のやり直しや、読み込み時の状態への初期化を行います。
- **保存**: 編集結果を新しいPDFファイルとして書き出します。

### 2. 左パネル：サムネイル一覧

- **全選択 / 解除 / 反転**: ページの一括操作に便利です。「反転」はすべてのチェック状態を逆にします。
- **サムネイル表示**: 各ページの縮小版が表示されます。
- **ドラッグ＆ドロップ**: サムネイルをマウスで掴んで移動させることで、ページ順序を入れ替えられます。
- **チェックボックス**: 複数ページを選択して、一括移動、コピーや削除を行う対象を指定します。

### 3. 中央パネル：PDFビューアー

- **プレビュー**: 選択中のページを表示します。
- **ズーム機能**: 内容を確認するための拡大・縮小が可能です。

### 4. 右パネル：操作パネル

#### ページ操作

- **選択を移動 / 選択をコピー**: チェックを入れたページを、指定した位置（先頭、末尾、または指定ページの後）へ移動・コピーします。
- **選択を削除**: チェックを入れたページを削除します。

#### 画像操作

- **自動解除（スイッチ）**: ONの場合、回転や切り抜き操作の後にチェック状態が自動でクリアされます。OFFにするとチェックを維持したまま連続で操作できます。
- **スキップ選択**: 指定した範囲のページを1つ置きに選択します（詳細は後述）。
- **左回転 / 右回転**: 90度ずつページの向きを修正します。
- **反転 (180°)**: ページを180度回転させます。
- **切り抜き (Crop)**: マウスで範囲を指定し、ページをトリミングします。

#### PDFを挿入

- 別のPDFや画像ファイルを、現在の構成の「先頭」「現在位置」「最後」のいずれかに差し込みます。

## 両面スキャン時の1枚おきの反転への対処

両面スキャン対応のスキャナー（自動原稿送り装置：ADF）でスキャンすると、機種や設定によっては**偶数ページ（裏面）が反転**になる場合があります。これは、用紙を自動で裏返してスキャンする際に発生する一般的な問題です。

本エディタの**「スキップ選択」機能**を使うことで、このような1枚おきに反転したページを簡単に一括修正できます。

### 手順

1. **PDFを開く**: 両面スキャンしたPDFファイルを開きます。
2. **「スキップ選択」ボタンをクリック**: 右パネルの画像操作セクションにある「スキップ選択」ボタンを押します。カーソルが十字に変わり、選択モードに入ります。
3. **開始ページをクリック**: サムネイル一覧から、反転しているページの最初のページ（通常は2ページ目＝偶数ページ）をクリックします。
4. **終了ページをクリック**: 反転しているページの最後のページ（通常は最終ページまたはその手前）をクリックします。
5. **1つ置きにチェックが入る**: 指定した範囲内のページが1ページおきに自動選択されます。
6. **「反転 (180°)」ボタンを押す**: 選択されたページが一括で180度回転され、正しい向きに修正されます。

> **ヒント**: 奇数ページが反転している場合は、1ページ目から開始してスキップ選択を行ってください。偶数ページの場合は2ページ目から開始します。

> **キャンセル**: スキップ選択モード中に `Esc` キーを押すと、選択操作をキャンセルして通常モードに戻ります。

## 基本的な使い方

1. **ファイルを開く**: 編集したいPDFを選びます。
2. **構成を編集**:
   - **順序入れ替え**: サムネイルをドラッグして移動。
   - **不要ページ削除**: チェックを入れて「選択を削除」。
   - **結合**: 「PDFを挿入」で別の資料を追加。
   - **両面スキャンの修正**: 「スキップ選択」→「反転 (180°)」で1枚おきの上下逆転を修正。
3. **保存**: 「保存」ボタンを押し、名前を付けてファイルを保存します。
