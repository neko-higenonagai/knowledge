# Editor (hgnn-editor.py) PDF Editor

## 概要

`hgnn-editor.py` は、PDFのページ構成を変更するための編集ツールです。ページの並べ替え、削除、回転、および別ファイルの挿入といった操作が行えます。

## 画面構成と機能

### 1. トップバー（画面最上部）

- **PDFを開く**: 編集したいファイルを選択します。画像ファイルを選択した場合は自動的にPDF化して読み込まれます。
- **アンドゥ / リセット**: 操作のやり直しや、読み込み時の状態への初期化を行います。
- **保存**: 編集結果を新しいPDFファイルとして書き出します。

### 2. 左パネル：サムネイル一覧

- **全選択 / 解除**: ページの一括操作に便利です。
- **サムネイル表示**: 各ページの縮小版が表示されます。
- **ドラッグ＆ドロップ**: サムネイルをマウスで掴んで移動させることで、ページ順序を入れ替えられます。
- **チェックボックス**: 複数ページを選択して、一括移動、コピーや削除を行う対象を指定します。

### 3. 中央パネル：PDFビューアー

- **プレビュー**: 選択中のページを表示します。
- **ズーム機能**: 内容を確認するための拡大・縮小が可能です。

### 4. 右パネル：操作パネル

- **ページ操作**:
  - **選択を移動 / 選択をコピー**: チェックを入れたページを、指定した位置（先頭、末尾、または指定ページの後）へ移動・コピーします。
  - **選択を削除**: チェックを入れたページを削除します。
- **回転**:
  - **左回転 / 右回転**: 90度ずつページの向きを修正します。
- **PDFを挿入**:
  - 別のPDFや画像ファイルを、現在の構成の「先頭」「現在位置」「最後」のいずれかに差し込みます。

## 基本的な使い方

1. **ファイルを開く**: 編集したいPDFを選びます。
2. **構成を編集**:
   - **順序入れ替え**: サムネイルをドラッグして移動。
   - **不要ページ削除**: チェックを入れて「選択を削除」。
   - **結合**: 「PDFを挿入」で別の資料を追加。
3. **保存**: 「保存」ボタンを押し、名前を付けてファイルを保存します。
