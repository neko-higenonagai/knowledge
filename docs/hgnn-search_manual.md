# Search (hgnn-search.py) テキスト検索

## 概要

`hgnn-search.py` は、ナレッジベース内のテキストを検索し、該当するページを即座に確認・編集するためのユーティリティです。大量の書類から特定のキーワードが含まれるページをピンポイントで探し出すのに適しています。

## 画面構成と機能

### 1. 検索バー（左パネル上部）

- **入力欄**: 検索したいキーワードを入力します。スペース区切りで複数キーワード（AND検索）が可能です。
- **検索ボタン**: 検索を実行します。
- **テキスト検索（スイッチ）**:
  - **OFF（インデックス検索）**: 形態素解析を利用した高速な全文検索を行います（推奨）。
  - **ON（テキスト検索）**: テキストの一致検索を行います。インデックス検索でうまくいかないときに有効です。

### 2. フィルターエリア（ヘッダー直下）

検索対象を特定のカテゴリに絞り込むためのエリアです。

- **大分類 / 中分類 / 小分類**: フォルダ構造に基づいたカテゴリ選択が可能です。選択すると、その下の階層の選択肢が動的に更新されます。
- **クリア**: すべてのフィルターを解除して「すべて」の状態に戻します。

### 3. 検索結果リスト（左パネル中央）

- **一覧表示**: ヒットしたページの「日付」「パス」「ファイル名」「ページ番号」がリストアップされます。
- **選択**: リストの項目をクリックすると、そのページのテキストが下のプレビューに表示され、右パネルのPDFビューアーに該当ページが表示されます。

### 4. テキストプレビュー（左パネル下部）

- **表示エリア**: 選択されたページのテキストが表示されます。検索キーワードは黄色でハイライトされます。
- **編集開始/キャンセル**: テキストを直接修正したい場合に使用します。
- **保存・再索引**: 修正したテキストをデータベースに保存し、検索インデックスを更新します。

### 5. PDFビューアー（右パネル全体）

- **表示**: PDFの内容をそのまま表示します。
- **ツールバー（ビューアー上部）**:
  - **前ページ / 次ページ**: ページを移動します。
  - **拡大 / 縮小**: 表示サイズを調整します。
  - **左回転 / 右回転**: 画面上の表示向きを変えます。
  - **元の位置**: 検索結果で最初に表示されたページに戻ります。
  - **外部アプリで開く**: AcrobatなどのOS標準ビューアーでファイルを開きます。

## 基本的な使い方

1. **キーワードで検索**: 探したい単語を入力して「検索」を押します。
2. **結果の確認**: リストから気になる項目を選びます。右側に実際の書類、左下に抽出されたテキストが表示されます。
3. **テキストの修正**: OCRの誤字を見つけた場合は「編集開始」→修正→「保存・再索引」を行うことで、次回の検索精度が向上します。
